Idea

  • Proposed solution: web tool that takes a .wav or raw IQ capture with no prior knowledge and reports sampling-derived parameters, modulation, FEC, interleaving and frame structure
  • How it addresses the problem: replaces manual analysis with an automated chain and shows its evidence (spectrum, constellation, confidence) at every step
  • Demodulates BPSK, QPSK, 8PSK, 16QAM, 2FSK, 4FSK
  • Decodes convolutional codes (Viterbi), Reed-Solomon and concatenated codes; de-interleaves block, diagonal, convolutional, pseudo-random
Innovation and uniqueness
  • Blind identification of the convolutional code and the RS code from the bits alone
  • Feed-forward estimators: no loops to tune, explainable from first principles
  • Bit-stream correlation finds sync word, header and payload
  • Second opinion from a CNN trained on public RadioML data
  • PDF evidence report per analysis

Own simulator, 20 captures per point. Not real captures.

Feasibility and viability

  • Feasible: runs on a laptop CPU; CNN is a 2.3 MB ONNX file
  • Measured (simulator): BER 0 at 8 dB full-band SNR for PSK/2FSK; conv K=7 decodes to ~2 % raw BER, RS(255,223) to ~0.3 %, RS+conv to ~3 %, LDPC(512,256) to ~4 %, RS+LDPC to ~4 %
  • Challenges and risks (stated plainly):
  • No real capture tested yet; transmitter and receiver share an author
  • BPSK sometimes mistaken for FSK (15-30 % in simulation)
  • CNN agrees with truth on 71 % of simulated captures; informational only
  • LDPC needs the parity-check matrix for non-built-in codes; no scramblers, puncturing, soft decisions; interleaver size supplied by operator
Blind decode success vs raw channel BER, own simulator and transmit chain.
  • Strategy: validate on public / RTL-SDR captures, ship the standard CCSDS and Wi-Fi LDPC matrices, soft-decision decoding

Impact and benefits

  • Analysts: minutes instead of hours for first-pass parameter identification; every conclusion shows its evidence
  • Trust: confidence, warnings and limits are shown; nothing is presented as certain when it is an estimate
  • Training and research: each algorithm is explainable; documented with known-answer tests
  • Reuse: works on files from different sensors (.wav or raw IQ cf32/ci16/ci8/cu8)
  • Low cost: open-source stack, no GPU or licence needed at run time
  • Roadmap: standard LDPC matrices, scrambler support, SigMF metadata, batch mode, GNU Radio flowgraph export
